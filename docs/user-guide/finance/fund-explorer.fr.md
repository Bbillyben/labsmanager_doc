# Explorateur de fonds

Choisissez **Tools → Fund explorer** pour comparer les postes de financement des projets que vous pouvez consulter. Chaque résultat est un **poste de financement** associé à un financement ; plusieurs lignes peuvent partager la même référence. Dans les données de démonstration, un filtre sur `DM-HELIX-GRANT` affiche quatre postes. Il s’agit d’une liste en lecture seule, pas d’une fiche de financement distincte.

## Trouver et comparer des postes

Filtrez par type de coût, montant disponible, activité, projet, institution, financeur, référence du financement ou participant. Le filtre **Overdue** est aussi disponible. Triez une colonne pour changer l’ordre ; **End date** aide à repérer les échéances les plus proches. La liste affiche le projet, le financeur, l’institution, les dates et la référence du financement, le type de coût, le montant, le montant consommé et le disponible. Ouvrez une ligne pour en voir les détails.

Le nom d’un projet, d’un financeur ou d’une institution n’ouvre sa fiche que si vous avez le droit de la consulter. Pour lire la synthèse d’un financement et ses dépenses, ouvrez son projet et sélectionnez-le dans **Funds** : [Consulter un financement](view-a-fund.md).

## Visibilité

L’explorateur ne renvoie que les postes dont les financements et les projets sont visibles pour votre compte. Un résultat manquant ne prouve pas qu’aucun financement n’existe. L’accès à l’outil dans la navigation ne donne pas accès aux données financières de tous les projets.
