# Budgets et dépenses

Les budgets d’un projet décrivent les affectations prévues. Les dépenses enregistrent les transactions individuelles. Les deux sont accessibles depuis la fiche du projet React lorsque vos droits le permettent.

## Lire les budgets d’un projet

Ouvrez un projet et choisissez **Budgets**. Chaque ligne indique le financement, le type de coût et la description, puis **Amount**, **Net expense** et **Available**. L’exemple ORION comporte des lignes distinctes pour ses financements et types de coût visibles. Sélectionnez une ligne de budget pour afficher les dépenses qui lui sont liées. Ouvrez ses détails si vous avez besoin du type de collaborateur ou de contrat associé, du collaborateur ou de la quotité.

<figure class="lm-screenshot" markdown>
![Tableau Budgets d’ORION avec financement, type de coût, montant, dépense nette et solde disponible](../../assets/screenshots/finance/budget-overview.png)
</figure>

La section **Contributions** est distincte des budgets. Ses lignes indiquent le financement, le type de coût, la description, le montant ainsi que les dates de début et de fin. Ouvrez une contribution pour examiner les détails de personnel et de quotité. Sa période et sa quotité ne remplacent pas le solde d’un budget.

## Examiner les dépenses

Après avoir sélectionné un financement dans **Funds**, **Individual expenses** affiche les transactions de ce financement. Après avoir sélectionné une ligne dans **Budgets**, la liste affiche celles du budget. Le tableau fournit la date, la référence, la description, le type de coût, le statut, le contrat, le budget et le montant. Utilisez la recherche et les filtres de type de coût et de période pour réduire la liste ; sélectionnez une ligne pour en lire les détails. L’exemple `DM-ORION-BRIDGE` présente des transactions datées sous plusieurs types de coût.

<figure class="lm-screenshot" markdown>
![Dépenses individuelles du financement relais d’ORION avec filtres et lignes de transaction](../../assets/screenshots/finance/expenses.png)
</figure>

Pour les dépenses de tous vos projets visibles, choisissez **Tools → Expenses**. Cette liste propose des filtres sur le type de coût, les dates, la description, le projet, le financeur, l’institution, la référence du financement, le statut et la référence de dépense. Vous pouvez trier les colonnes disponibles et parcourir les pages de résultats.

Les commandes d’ajout, de modification, de suppression ou de synchronisation des dépenses n’apparaissent que si vos droits le permettent. Ce guide explique la lecture des informations financières ; consultez votre procédure locale avant de les modifier.

Voir [Consulter un financement](view-a-fund.md) pour sa synthèse ou [Explorateur de fonds](fund-explorer.md) pour la vue transversale.
