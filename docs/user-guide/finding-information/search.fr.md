# Rechercher et filtrer des informations

Utilisez la recherche globale lorsque vous connaissez un nom ou un terme, mais pas sa rubrique. Utilisez la recherche, les filtres et le tri d’une liste lorsque vous connaissez déjà le type d’élément recherché.

## Rechercher dans LabsManager

1. Sélectionnez l’icône de recherche dans la barre supérieure.
2. Saisissez le nom d’un collaborateur, d’un projet ou un terme lié à un financement.
3. Parcourez les résultats correspondants. Ouvrez la fiche voulue ou sélectionnez **View all results** pour afficher la liste complète.

La recherche n’affiche que les informations accessibles à votre compte. Si un élément manque, vérifiez l’orthographe et essayez un terme plus court. Les restrictions d’accès peuvent aussi limiter les résultats.

## Affiner une liste

1. Ouvrez la rubrique concernée, par exemple **Employees** ou **Projects**.
2. Saisissez un terme dans la recherche de la liste ou choisissez un filtre disponible.
3. Triez les résultats si cela facilite leur comparaison, puis ouvrez la ligne correspondante.

Les filtres proposés dépendent de la liste. Effacez ou modifiez un filtre si l’élément attendu n’apparaît pas. Les longues listes peuvent comporter plusieurs pages.
