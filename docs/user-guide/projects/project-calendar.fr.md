# Consulter le calendrier d’un projet

Utilisez **Calendar** dans la fiche d’un projet pour voir les événements propres à ce contexte. Ce guide couvre le mode **Calendar** en vue **Month**.

## Choisir un mois

1. Ouvrez ORION — Optical Resilience et sélectionnez **Calendar**.
2. Choisissez **Calendar** et **Month** si un autre mode ou une autre période est sélectionné.
3. Utilisez les commandes précédent et suivant pour changer de mois, ou **Today** pour revenir à la période actuelle. Vérifiez les dates affichées avant de lire les événements.
4. Utilisez les filtres visibles pour affiner les événements. Ouvrez un événement lorsque vous avez besoin des détails accessibles à votre compte.

Le calendrier peut afficher des événements liés au projet, notamment les absences enregistrées pour ses participants. Les événements et actions visibles dépendent de vos droits et de la configuration active. Un mois sans événement visible ne prouve pas qu’aucun travail n’est prévu ; les tâches et jalons se lisent dans leur [section dédiée](tasks-and-milestones.md).
