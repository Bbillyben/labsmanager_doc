# Generate reports and export lists

You can download a report for a person or project when your account has access to that record and its report format. List exports are a separate way to download rows you can see.

## Download an Employee or Project report

Open the [Employee record](../people/view-person.md) or [Project record](../projects/view-project.md), then open the action menu beside its heading. Choose **Export Word** or **Export PDF**. An action appears only when your account may use that format for the record. The choice opens a report dialog for the selected record and format; there is no separate report-selection page.

In the dialog, choose a **Template**. The list comes from the templates available for that record type and format. The first available template is selected automatically. If the list says **No template available**, the export button is disabled; ask someone who manages report templates for your installation. The same applies if the template list fails to load, except that an error message appears.

![Camille ORREN Employee Word report dialog with a selected template and From and To dates](../../assets/screenshots/reports-and-exports/employee-word-dialog.png)

For an **Employee** report, you can set **From** and **To** dates. They initially span the previous year through today; clear a date to leave that boundary open. If both dates are set, **From** must not be later than **To**. The template determines how it uses the dates. A **Project** report has no period fields.

![ORION Project PDF report dialog with a selected template and no period fields](../../assets/screenshots/reports-and-exports/project-pdf-dialog.png)

Choose **Export** to generate and download the document. The dialog stays open while it runs and closes after a successful download. If generation fails, it shows an error so you can try again. Word downloads use a `.docx` file; PDF downloads use a `.pdf` file. The application may use a filename supplied with the generated file. React provides the selection and download controls; the document itself is generated by the server. There is no React preview of the finished file in this workflow.

The demonstration data includes Camille ORREN and ORION — Optical Resilience as stable examples. Whether their Word/PDF actions and template choices are available in your installation still depends on permissions and installed templates.

## Export a list

The **Employees**, **Projects**, **Teams** and **Contracts** lists, as well as the financial **Fund explorer**, **Budget explorer** and **Expenses** tools, expose an **Export** button. It opens a different dialog: choose **XLSX**, **CSV**, **TSV** or **XLS**, then download. This export uses the current list filters and visible data scope; it is not limited to the current pagination page. It does not ask for a report template or produce a Word/PDF report.

You can close either dialog without downloading. Available actions and exported content depend on your access to the underlying records.
