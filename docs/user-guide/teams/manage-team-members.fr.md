# Gérer les membres d’une équipe

Vous ne pouvez modifier une équipe que si votre compte dispose du droit correspondant. Ouvrez **Teams**, puis sélectionnez l’équipe. Si les commandes décrites ci-dessous ne s’affichent pas, renseignez-vous auprès d’un administrateur des équipes sur vos droits.

## Créer ou modifier une équipe

Dans la liste Teams, choisissez **Add Team** si cette action est disponible. Saisissez un nom et choisissez un responsable si le formulaire le permet. Certains comptes ont un responsable par défaut imposé. Enregistrez pour créer l’équipe. Sur la fiche d’une équipe, utilisez **Edit** dans **Information** pour modifier ses informations si cette action est disponible.

## Ajouter un membre

Dans **Information**, choisissez **Add member**. Recherchez le collaborateur, renseignez si nécessaire les dates de début et de fin d’appartenance, puis sélectionnez **Save**. La personne choisie doit déjà avoir une fiche collaborateur. Le sélecteur exclut le responsable de l’équipe et les personnes déjà inscrites comme membres.

## Modifier ou retirer un membre

Ouvrez le menu d’actions de sa ligne. **Edit** permet de modifier le collaborateur ou les dates d’appartenance si vos droits le permettent. **Delete** supprime l’appartenance après confirmation. Ces actions dépendent des droits sur ce membre : deux lignes peuvent donc proposer des choix différents. Si des dates sont saisies, la date de fin ne doit pas précéder la date de début.

Pour consulter les informations et le travail de la personne, ouvrez sa [fiche collaborateur](../people/view-person.md). Les changements d’appartenance effectués ici ne remplacent pas le parcours distinct du guide People.
