# Utiliser les calendriers

Choisissez **Calendars** dans la navigation principale pour ouvrir les calendriers couvrant les fiches auxquelles vous avez accès. La page comporte les onglets **General calendar** et **Project calendar**. Passez de l’un à l’autre pour changer les informations affichées ; les filtres et les commandes de date changent avec l’onglet.

## Lire le calendrier général

**General calendar** s’ouvre en premier. Son mode **Calendar** affiche les congés visibles des collaborateurs sur la période choisie. D’autres événements peuvent apparaître si des plugins sont activés. Choisissez **Resources** pour organiser le même calendrier par collaborateur. Dans Resources, utilisez le sélecteur de ressources pour afficher les collaborateurs ayant des événements sur la période visible, tous les collaborateurs visibles ou ceux ayant un événement aujourd’hui. Ce dernier choix recherche les événements du jour même si vous consultez une autre période.

Utilisez les commandes précédent et suivant pour parcourir le temps, ou **Today** pour revenir à la période actuelle. Choisissez **15 days**, **Month**, **2 months** ou **Year** pour modifier l’étendue. Vérifiez les dates affichées après ce changement.

Les filtres au-dessus du calendrier permettent de restreindre les collaborateurs par activité, statut actuel, équipe, collaborateur précis ou type de congé. Si un plugin fournit des filtres de calendrier, ses commandes apparaissent séparément sous les filtres standard. Les événements et filtres disponibles dépendent de vos droits et des plugins installés. Une période vide signifie qu’aucun élément visible ne correspond à la sélection actuelle.

Sélectionnez un congé pour ouvrir ses détails, dont les dates et le lien vers le collaborateur lorsqu’il est disponible. Ce calendrier transversal est une vue de consultation : il ne permet pas de créer, déplacer, redimensionner ou modifier un congé. Les événements de plugin peuvent afficher des informations ou une infobulle sans ouvrir de fiche de congé.

L’action **Print** prépare une vue imprimable de la période et des filtres actuels. **Presentation** masque les filtres et propose un bouton de sortie ; les données ne changent pas. Cette page ne comporte pas d’action d’export.

## Lire l’onglet Project calendar

L’onglet **Project calendar** de cette page est une chronologie de planification transversale aux projets. Il montre les projets visibles, leurs tâches et jalons, ainsi que les éventuels événements de calendrier fournis par les plugins. Utilisez les commandes précédent et suivant, ou **Current**, pour déplacer la fenêtre. Choisissez **6**, **12**, **24**, **60** ou **120 months** pour en modifier la durée. Les filtres peuvent restreindre les projets actifs ou en retard, l’équipe, l’institution, le financeur, un projet précis ou le statut des jalons. Des filtres de plugin peuvent également apparaître ici.

Sélectionnez un projet pour ouvrir sa fiche, ou une tâche ou un jalon pour lire son panneau de détails. Cet onglet propose également **Print** pour la chronologie actuelle. Il sert à la consultation ; aucune commande de modification n’y est exposée. Les éléments affichés dépendent des projets et éléments de planification que vous pouvez voir.

Pour le calendrier et les événements d’un seul projet, utilisez le [calendrier du projet](../projects/project-calendar.md). Pour ses tâches et jalons, consultez [Tâches et jalons](../projects/tasks-and-milestones.md).
