# Personnaliser votre tableau de bord

Utilisez **Customize** sur un tableau de bord pour modifier les informations affichées ou leur disposition. Les données disponibles dans les widgets restent soumises aux droits de votre compte.

## Ajouter ou modifier un widget

Sélectionnez **Customize** pour afficher le catalogue des widgets. Recherchez une source ou parcourez ses catégories, puis sélectionnez une source pour choisir sa présentation et ses paramètres disponibles. Enregistrez pour ajouter le widget. Une source qui ne peut pas être ajoutée deux fois au même tableau de bord est indiquée comme déjà ajoutée.

Ouvrez le menu d’actions d’un widget pour le configurer ou le supprimer. La suppression demande une confirmation. Lorsque vous avez terminé, sélectionnez **Done** pour quitter le mode de personnalisation.

## Organiser la disposition

Sur un écran large, faites glisser un widget par sa poignée ou redimensionnez-le depuis un coin tant que **Customize** est actif. Sélectionnez **Save layout** pour conserver la nouvelle disposition. Sur un écran étroit, les widgets s’empilent : leur déplacement et leur redimensionnement ne sont alors pas disponibles. La page React actuelle ne propose pas de commande pour rétablir la disposition initiale.

## Gérer les tableaux de bord personnels

Pendant la personnalisation d’un tableau de bord personnel, vous pouvez le renommer, le dupliquer, changer son ordre, le définir par défaut ou le supprimer. **Set as default** est disponible si ce tableau de bord n’est pas déjà celui par défaut. Le tableau de bord par défaut s’ouvre en premier lorsque vous revenez à Dashboard. Sa suppression, qui supprime aussi ses widgets, demande une confirmation.

Ces commandes concernent les tableaux de bord personnels. La section Dashboard d’un projet a son propre périmètre et n’affiche pas le sélecteur de tableaux de bord personnels.

Revenez à [Utiliser votre tableau de bord](use-your-dashboard.md) pour comparer les vues initiales préparées.
