# Customize your dashboard

Use **Customize** on a dashboard when you want to change the information or arrangement you see. The available widget data still follows your account's permissions.

## Add or change a widget

Select **Customize** to show the widget catalogue. Search for a source or browse its categories, then select a source to choose its display and available settings. Save it to add the widget. A source that cannot be added twice to the same dashboard is marked as already added.

Open a widget's actions menu to configure it or remove it. Removing a widget asks for confirmation. When you finish, select **Done** to leave customization mode.

## Arrange the layout

On a wide screen, drag a widget by its handle or resize it from its corner while **Customize** is active. Select **Save layout** to keep the new arrangement. On a narrow screen the widgets stack, so dragging and resizing are not available there. The current React page does not offer a reset-layout control.

## Manage personal dashboards

While customizing a personal dashboard, you can rename or duplicate it, change its order, set it as the default, or delete it. **Set as default** is available for a dashboard that is not already the default. The default dashboard is the one opened first when you return to Dashboard. Deleting a dashboard also deletes its widgets and asks for confirmation.

These management controls are for personal dashboards; a project's Dashboard section has its own scope and does not show the personal dashboard selector.
