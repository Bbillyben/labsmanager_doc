# Consulter les absences d’un collaborateur

Ouvrez l’onglet **Leave** d’un collaborateur pour voir ses absences enregistrées. Vous pouvez les afficher en calendrier ou en tableau : choisissez la vue la plus utile à votre question.

## Trouver des absences sur une période

1. Ouvrez le collaborateur depuis **Employees**, puis sélectionnez **Leave**.
2. Choisissez **Calendar** pour situer les dates dans le temps, ou **Table** pour comparer les absences.
3. Allez à la période voulue ou utilisez les filtres de type d’absence et de dates pour affiner la vue.
4. Ouvrez une absence pour consulter ses détails lorsque votre compte y a accès.

Le tableau indique le type d’absence, le début, la fin, la durée et l’éventuel commentaire. Le calendrier aide à situer une absence dans le temps. Camille ORREN possède des absences de démonstration passées et à venir ; la capture retenue utilise **Table** pour les montrer clairement.

Les commandes **Add leave** et de modification n’apparaissent que si vous avez les droits requis. Ce guide explique comment trouver et lire les absences ; les instructions de modification feront partie d’un lot ultérieur.
