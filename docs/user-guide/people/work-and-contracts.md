# A person's projects and contracts

Use a person's record to see where they work and which contracts are linked to them. Start from [View a person](view-person.md), then choose the tab that answers your question.

## See project participation

1. Open the person's **Projects** tab.
2. In **List** view, find the **Projects** section. Each participation shows the project, the person's role, its period, allocation and current or historical status.
3. Open a project name when it is a link and you need the project's own record.

The tab also has a **Gantt** view and a milestones section. Use them to orient yourself in the person's work; detailed planning guidance belongs to the project guide. A project name may appear without a link when you cannot open that project separately.

## See contracts

1. Open the person's **Contracts** tab.
2. Read the contract type, associated project, period, allocation and status in the list.
3. Select a row if you need the details available for that contract.

Compare the dates with the period you are interested in. A contract's **Effective** or **Provisional** label describes its status; it does not by itself tell you whether the contract covers today.

The list and its actions depend on what you may see or change. **Add contract**, edit and delete controls appear only when available to your account. Camille ORREN has a contract linked to ORION in the demonstration dataset.
