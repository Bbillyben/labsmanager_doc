# Premiers pas

LabsManager aide les membres du laboratoire et les responsables de projet à retrouver les personnes, les projets et les informations liées à leur activité.

La documentation française est en préparation. Les autres pages de ce guide sont actuellement disponibles en anglais. Vous pouvez [découvrir l’interface](interface.md) ou [rechercher une information](../finding-information/search.md).
