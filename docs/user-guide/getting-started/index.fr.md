# Premiers pas

LabsManager aide les membres du laboratoire et les responsables de projet à retrouver les collaborateurs, les projets et les informations liées à leur activité. Commencez par la page d’accueil, puis ouvrez la rubrique correspondant à votre tâche.

## Ouvrir LabsManager

Connectez-vous avec la méthode fournie par votre organisation. Ouvrez le lien vers l’application LabsManager transmis par votre équipe. Si vous ne pouvez pas vous connecter ou si une rubrique attendue manque, contactez votre administrateur local : l’accès dépend de votre compte.

## Partir de la page d’accueil

Utilisez la navigation principale pour accéder aux collaborateurs, aux projets et aux autres rubriques disponibles. La page d’accueil peut aussi afficher les éléments consultés récemment. Sélectionnez un élément récent pour y revenir, ou utilisez la [recherche et les filtres](../finding-information/search.md) pour trouver autre chose.

## Choisir un parcours

- Pour retrouver un collaborateur, utilisez la [recherche et les filtres](../finding-information/search.md), puis [consultez sa fiche](../people/view-person.md).
- Pour comprendre un projet, [ouvrez sa fiche](../projects/view-project.md).
- Pour savoir où apparaissent les actions et les informations liées, [découvrez l’interface](interface.md).

Les rubriques et actions visibles dépendent de vos droits et des informations disponibles dans votre organisation.
